# CakeShop E-commerce System


## Custom Dashboard

CakeShop includes a custom admin dashboard
for managing the complete e-commerce system.


## Dashboard Features

### Analytics

- Total Cakes Count
- Total Customers
- Total Orders
- Total Revenue


### Product Management

- Add New Cakes
- Update Cake Details
- Delete Cakes
- Manage Categories


### Order Management

- View Customer Orders
- Update Order Status
- Track Order Progress


### User Management

- Manage Customers
- View User Information


### Reports

- Sales Analytics
- Revenue Reports
