
# CakeShop E-Commerce API Project

CakeShop is a Django REST API based e-commerce application for an online cake shop.

The project includes customer authentication, cake and category management,
shopping cart, order placement, order tracking, and a custom admin dashboard.

## Technologies Used

- Python
- Django
- Django REST Framework
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite
- JWT Authentication
- Git & GitHub

## User Features

### Authentication

- User Registration
- User Login
- JWT Authentication
- User Logout


### Shopping Cart

- Add Cake to Cart
- View Cart
- Update Cart
- Remove Cake from Cart

### Orders

- Place Order
- View My Orders
- View Order Details

## Custom Dashboard

CakeShop includes a custom admin dashboard
for managing the complete e-commerce system.


## Dashboard Features

### Analytics

- Total Cakes Count
- Total Customers
- Total Orders
- Total Revenue


### Product Management

- Add New Cakes
- Update Cake Details
- Delete Cakes
- Manage Categories


### Order Management

- View Customer Orders
- Update Order Status
- update payment status
